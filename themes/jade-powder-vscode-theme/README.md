# Jade Powder

A coordinated light and dark VS Code theme pair built from:

- Bright Snow `#FCFAFA`
- Silver `#C8D3D5`
- Powder Blue `#A4B8C4`
- Slate Grey `#6E8387`
- Jade Green `#0CCA4A`

Included themes:

- **Jade Powder Light**
- **Jade Powder Dark**

Both variants use jade green for focus, success, types, and strings; powder blue and slate grey for structure; and bright snow for clean high-contrast text.

## Install

Copy `jade-powder-vscode-theme` into:

- Windows: `%USERPROFILE%\.vscode\extensions`
- macOS/Linux: `~/.vscode/extensions`

Restart VS Code and choose either **Jade Powder Light** or **Jade Powder Dark**.
