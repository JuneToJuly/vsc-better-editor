# Bright Ocean Light

A vivid light VS Code theme built from the user-selected palette:

- Bright Ocean `#3C91E6`
- Yellow Green `#9FD356`
- Shadow Grey `#342E37`
- Porcelain `#FAFFFD`
- Coral Glow `#FA824C`

The UI uses porcelain surfaces, shadow-grey structure, blue focus states, green secondary accents, and coral activity/debug highlights.

## Install

Copy the `bright-ocean-light-vscode-theme` folder into:

- Windows: `%USERPROFILE%\.vscode\extensions`
- macOS/Linux: `~/.vscode/extensions`

Restart VS Code, run **Preferences: Color Theme**, and select **Bright Ocean Light**.
