# Lime Carnation Soft Glow

A softly blended refinement of Lime Carnation Light.

Highlights:

- low-saturation lavender title bar and command center
- porcelain editor with gentle lavender current-line treatment
- white-lavender sidebars and panels that blend into the center
- dusty-grape activity bar for structure
- pink annotations and control flow
- indigo functions and methods
- lime strings
- stronger but softer test failure treatment

This package has a unique extension ID and theme name, so it can be installed beside previous Lime Carnation versions.

## Install

Copy `lime-carnation-soft-glow-vscode-theme` into:

- Windows: `%USERPROFILE%\.vscode\extensions`
- macOS/Linux: `~/.vscode/extensions`

Restart VS Code and select **Lime Carnation Soft Glow**.
