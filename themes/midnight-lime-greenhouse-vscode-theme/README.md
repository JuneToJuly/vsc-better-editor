# Midnight Lime Greenhouse

A calmer, more coherent Midnight Lime theme.

Design:

- iron-grey editor surfaces instead of near-black
- midnight violet reserved for chrome and atmosphere
- lime reserved for types, strings, cursor, search, success, and Git additions
- amber declarations and control flow
- silver methods and variables
- muted violet annotations and fields
- fewer outlines and quieter borders

This package installs beside previous Midnight Lime versions.

## Install

Copy `midnight-lime-greenhouse-vscode-theme` into:

- Windows: `%USERPROFILE%\.vscode\extensions`
- macOS/Linux: `~/.vscode/extensions`

Restart VS Code and select **Midnight Lime Greenhouse**.
