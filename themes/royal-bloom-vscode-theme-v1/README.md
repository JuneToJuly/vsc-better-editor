# Royal Bloom Theme v1

A vivid dark VS Code theme built from:

- Royal Violet `#731DD8`
- Lime Yellow `#E0FF4F`
- Vibrant Coral `#FF6663`
- Plum `#DF99F0`
- Soft Periwinkle `#B191FF`

The theme uses a lifted violet-black workspace instead of pure black and assigns each accent a specific role:

- Coral: keywords and control flow
- Lime: functions, methods, constants, and active emphasis
- Plum: types, classes, and structural symbols
- Periwinkle: operators, namespaces, focus, and secondary accents
- Soft green derived from lime: strings

## Install

1. Extract this folder into your VS Code extensions directory.
2. Reload VS Code.
3. Run **Preferences: Color Theme**.
4. Select **Royal Bloom Night v1**.
