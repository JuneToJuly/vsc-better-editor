# Raspberry Spectrum Themes

A dark and light VS Code theme pair built from:

- Raspberry Red `#CE2D4F`
- Blush Rose `#CE6D8B`
- Thistle `#CEBBC9`
- Full Spectrum Blue `#4056F4`
- Electric Blue-Violet `#470FF4`

Both variants include extensive workbench theming, TextMate scopes, semantic token colors, bracket-pair colors, terminal ANSI colors, Git and diff states, testing, debugging, tabs, Explorer, panels, notifications, and editor widgets.

## Install

1. Extract the ZIP.
2. Open the extracted folder in VS Code.
3. Run `npm install -g @vscode/vsce` if needed.
4. Run `vsce package`.
5. Install the generated VSIX using **Extensions: Install from VSIX...**.

Choose **Raspberry Spectrum Light** from **Preferences: Color Theme**.
