# Powder Slate

A paired light and dark VS Code theme based on:

- `#EDD3C4` Powder Petal
- `#C8ADC0` Thistle
- `#7765E3` Medium Slate Blue
- `#3B60E4` Slate Indigo
- `#080708` Black

Included themes:

- **Powder Slate Light**
- **Powder Slate Dark**

## Install

Extract the folder into your VS Code extensions directory:

- Windows: `%USERPROFILE%\.vscode\extensions\powder-slate-theme-1.0.0`
- Linux/macOS: `~/.vscode/extensions/powder-slate-theme-1.0.0`

Restart VS Code and choose either theme from **Preferences: Color Theme**.

## Development

Open this folder in VS Code and press `F5`.
