# Navy Electric Dual

A dark and light VS Code theme pair built around:

- `#190094` Navy Electric
- `#FEFFFE` White

## Included themes

- **Navy Electric Dark**
- **Navy Electric Light**

Both include full workbench styling, semantic highlighting, TextMate scopes, bracket colors, terminal ANSI colors, Git decorations, diffs, testing, widgets, menus, tabs, Explorer, panels, minimap, and notifications.
