# Black Ice Palette

Two VS Code themes built from `#000100`, `#A1A6B4`, `#94C5CC`, `#B4D2E7`, and `#F8F8F8`.

- **Black Ice Soft** lifts the editor and panels away from pure black while retaining a dark cool-steel identity.
- **Black Ice Daylight** uses Bright Snow and Pale Sky surfaces with darker syntax colors for clear daytime readability.

Install the folder as a VS Code extension and choose either theme from **Preferences: Color Theme**.
