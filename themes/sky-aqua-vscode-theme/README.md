# Sky Aqua

Version 1.2.0 refines Java and TypeScript syntax highlighting to match the original visual reference.

A bright, airy Visual Studio Code theme built around:

- `#49C6E5` Sky Aqua
- `#54DEFD` Bright Sky Aqua
- `#FFFDFB` Snow
- `#00BD9D` Mint Leaf
- `#8BD7D2` Pearl Aqua

## Install locally

1. Copy this folder into your VS Code extensions directory:
   - Windows: `%USERPROFILE%\.vscode\extensions\sky-aqua-theme-1.0.0`
   - Linux/macOS: `~/.vscode/extensions/sky-aqua-theme-1.0.0`
2. Restart VS Code.
3. Run **Preferences: Color Theme**.
4. Select **Sky Aqua**.

## Development

Open this folder in VS Code and press `F5` to launch an Extension Development Host.
