# Lime Carnation Light

A vivid light VS Code theme built from:

- Lime Cream `#EDF67D`
- Pink Carnation `#F896D8`
- Mauve Magic `#CA7DF9`
- Majorelle Blue `#724CF9`
- Dusty Grape `#564592`

The design uses a warm near-white editor, dusty grape structure, Majorelle blue for primary syntax and focus, pink for control flow and debugging, mauve for selections, and lime for strings, search, badges, and secondary accents.

## Install

Copy the `lime-carnation-light-vscode-theme` folder into:

- Windows: `%USERPROFILE%\.vscode\extensions`
- macOS/Linux: `~/.vscode/extensions`

Restart VS Code, run **Preferences: Color Theme**, and select **Lime Carnation Light**.
