# Aurora Mint Theme v1

Two VS Code themes based on:

- Electric Blue `#30AFFF`
- Sky Cyan `#92EEFF`
- Mint Cream `#D8FFC5`
- Soft Green `#C4F7CA`

Included themes:

- **Aurora Mint Day v1**
- **Aurora Mint Night v1**

## Install

Extract this folder into your VS Code extensions directory, reload VS Code, then run **Preferences: Color Theme**.
