# Neon Amethyst Palette

Two VS Code themes built from:

- Dark Amethyst `#4C1A57`
- Fuchsia Pop `#FF3CC7`
- Yellow `#F0F600`
- Neon Ice `#00E5E8`
- Deep Ocean `#007C77`

## Included themes

- **Neon Amethyst Night** — lifted amethyst surfaces, cyan structure, fuchsia keywords, yellow callables, and balanced teal strings.
- **Neon Amethyst Day** — a soft purple-paper light theme with clearer sidebar and tab separation, teal strings, cyan types, yellow functions, and fuchsia language keywords.

## Version 1.1.0 refinements

- Replaced the mismatched green string color with muted teal.
- Added a subtle purple paper editor background.
- Strengthened explorer, selection, hover, and tab hierarchy.
- Rebalanced semantic tokens so each accent has a distinct job.

## Install

Extract this folder into your VS Code extensions directory, reload VS Code, and choose a theme using **Preferences: Color Theme**.
