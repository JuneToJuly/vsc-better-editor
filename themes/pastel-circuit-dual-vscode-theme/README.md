# Pastel Circuit: Nocturne & Daybreak

A refined VS Code theme pair built from pastel pink (`#FFC1CF`), tea green (`#E8FFB7`), mauve (`#E2A0FF`), light cyan (`#C4F5FC`), and aquamarine (`#B7FFD8`).

## Themes

- **Pastel Circuit Nocturne** — layered charcoal surfaces, softened pastel syntax, and restrained highlights for long coding sessions.
- **Pastel Circuit Daybreak** — a cool near-white canvas with darker pastel-derived syntax and clearly separated workbench surfaces.

Both themes include semantic highlighting, TextMate scopes, bracket-pair colors, Git and diff states, terminal ANSI colors, testing, debugging, tabs, Explorer, panels, notifications, peek views, and editor widgets.

## Install

1. Extract this ZIP.
2. Copy the extracted folder into your VS Code extensions directory, then reload VS Code.
3. Choose **Preferences: Color Theme** and select either theme.

For a VSIX, run `npx @vscode/vsce package` inside the extracted folder, then use **Extensions: Install from VSIX...**.
