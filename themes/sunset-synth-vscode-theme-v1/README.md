# Sunset Synth Theme v1

Two VS Code themes based on:

- Deep Indigo `#1A05A2`
- Royal Magenta `#8F0177`
- Crimson Pink `#DE1A58`
- Sunset Orange `#F67D31`

Included themes:

- **Sunset Synth Day v1**
- **Sunset Synth Night v1**

## Install

Extract this folder into your VS Code extensions directory, reload VS Code, then run **Preferences: Color Theme**.
