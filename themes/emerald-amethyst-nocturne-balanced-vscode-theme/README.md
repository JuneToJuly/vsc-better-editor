# Emerald Amethyst Nocturne Balanced

This keeps the original Emerald Amethyst Nocturne design and specifically fixes the orange cast in the Explorer, tabs, and general workbench text.

Changes:

- neutral ghost-white Explorer text
- softer inactive file and folder labels
- white active tab text
- cool gray inactive tab text
- amethyst modified-file decorations instead of orange
- emerald added/untracked file decorations
- teal renamed-file decorations
- controlled gold only for warnings
- preserved dark teal surfaces, emerald syntax, and amethyst chrome

This extension installs separately from the prior versions.

## Install

Copy `emerald-amethyst-nocturne-balanced-vscode-theme` into:

- Windows: `%USERPROFILE%\.vscode\extensions`
- macOS/Linux: `~/.vscode/extensions`

Restart VS Code and select **Emerald Amethyst Nocturne Balanced**.
