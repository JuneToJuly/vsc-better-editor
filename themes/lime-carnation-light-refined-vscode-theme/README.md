# Lime Carnation Light Refined

A stronger version of Lime Carnation Light with:

- a vivid Majorelle-blue title bar
- darker, clearer editor text
- sharper function/type/variable separation
- cleaner lime strings
- a more visible current line
- deeper lavender panel and terminal surfaces
- stronger failed-test and error states
- brighter selections and active tabs

This extension has a unique ID and theme name, so it can be installed beside the original for direct comparison.

## Install

Copy `lime-carnation-light-refined-vscode-theme` into:

- Windows: `%USERPROFILE%\.vscode\extensions`
- macOS/Linux: `~/.vscode/extensions`

Restart VS Code and select **Lime Carnation Light Refined**.
