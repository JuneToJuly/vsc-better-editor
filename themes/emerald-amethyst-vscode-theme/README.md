# Emerald Amethyst

A dark VS Code theme built from:

- Emerald `#23CE6B`
- Jet Black `#272D2D`
- Ghost White `#F6F8FF`
- Amethyst `#A846A0`
- Charcoal `#50514F`

Design:

- jet-black/charcoal surfaces
- emerald types, cursor, focus, success, and Git additions
- amethyst keywords, fields, badges, and secondary actions
- ghost-white methods and variables
- mint strings
- muted gold numbers and constants

## Install

Copy `emerald-amethyst-vscode-theme` into:

- Windows: `%USERPROFILE%\.vscode\extensions`
- macOS/Linux: `~/.vscode/extensions`

Restart VS Code and select **Emerald Amethyst**.
