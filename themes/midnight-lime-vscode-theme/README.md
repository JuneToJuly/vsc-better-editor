# Midnight Lime

A dark VS Code theme based on:

- Grey Olive `#848C8E`
- Iron Grey `#435058`
- Lime Cream `#DCF763`
- Silver `#BFB7B6`
- White Smoke `#F1F2EE`
- Midnight Violet `#30011E`

The theme uses lime as the primary accent and midnight violet as the secondary hue. Java syntax avoids the usual blue-method/red-keyword pattern:

- control flow: lime
- declarations and keywords: warm sand
- methods: silver lavender
- classes and types: lime ivory
- fields and properties: magenta
- annotations: bright orchid
- strings: lime cream
- constants: rose

## Install

Copy `midnight-lime-vscode-theme` into:

- Windows: `%USERPROFILE%\.vscode\extensions`
- macOS/Linux: `~/.vscode/extensions`

Restart VS Code and select **Midnight Lime** from **Preferences: Color Theme**.
