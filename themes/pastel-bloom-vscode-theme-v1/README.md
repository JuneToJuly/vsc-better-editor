# Pastel Bloom Theme v1

A warm, paper-like light theme built from:

- Butter Yellow `#FFEA6C`
- Soft Cream `#FFFBA7`
- Pastel Pink `#FFA6FB`
- Vivid Pink `#FF61F8`

## Included theme

- **Pastel Bloom Day v1**

The theme uses a warm off-white editor, cream sidebars, plum structure, pink keywords, golden functions, olive-gold strings, and extensive semantic-token coverage.

## Install

Extract this folder into your VS Code extensions directory, reload VS Code, then select **Pastel Bloom Day v1** using **Preferences: Color Theme**.
