# Emerald Amethyst Nocturne

A deeper refinement of Emerald Amethyst based on the generated visual mockup.

Highlights:

- near-black blue-green editor and panels
- subtle amethyst chrome instead of large purple surfaces
- emerald types, strings, cursor, success states, and Git additions
- ghost-white methods and variables
- muted amethyst keywords, annotations, and fields
- softer selections and current-line treatment
- cleaner borders and stronger visual depth

This extension installs beside the original **Emerald Amethyst**.

## Install

Copy `emerald-amethyst-nocturne-vscode-theme` into:

- Windows: `%USERPROFILE%\.vscode\extensions`
- macOS/Linux: `~/.vscode/extensions`

Restart VS Code and select **Emerald Amethyst Nocturne**.
