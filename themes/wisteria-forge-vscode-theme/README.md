# Wisteria Forge

A dual VS Code theme built around:

- `#7699D4` Wisteria Blue
- `#242331` Shadow Grey
- `#FBFBFB` White
- `#BF2B2B` Flag Red
- `#8F95D3` Wisteria Accent

## Included themes

- **Wisteria Forge Dark**
- **Wisteria Forge Light**

Both variants include full workbench styling, semantic highlighting, TextMate scopes, bracket-pair colors, terminal ANSI colors, Git decorations, diffs, testing, widgets, menus, tabs, Explorer, panels, minimap, and notifications.
