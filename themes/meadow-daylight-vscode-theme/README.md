# Meadow Daylight

A soft illustrated-countryside-inspired VS Code light theme.

## Install

1. Extract this ZIP.
2. Open the extracted folder in a terminal.
3. Run `npx @vscode/vsce package` if you want a VSIX, or copy the folder into your VS Code extensions directory.
4. Reload VS Code and select **Meadow Daylight** from **Preferences: Color Theme**.

## About the illustrated background

A normal VS Code color theme cannot add wallpaper, gradients, rounded editor frames, vines, clouds, or decorative illustrations. Those require unsupported CSS injection or a separate background extension.

The `optional-wallpaper` folder contains a safe template showing the intended layering. Supply your own background image and use it only if you are comfortable with a CSS-loader extension that modifies VS Code's workbench.
